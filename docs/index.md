# FM - Terminal File Manager

Welcome to the documentation for **fm**, a fast, modular, and feature-rich TUI (Terminal User Interface) file manager written in Go.

`fm` is designed for power users who want a high-performance file management experience directly in their terminal. It combines the speed of Go with a modern, intuitive interface and advanced features like remote access, git integration, and deep content search.

## Core Philosophies

- **Performance First:** Built with a modular concurrent architecture to ensure smooth navigation even in large directories.
- **Modern TUI:** Uses the latest TUI principles to provide a beautiful and responsive interface.
- **Power Features:** Includes features often missing in terminal file managers, such as multi-tab support and background operation tracking.
- **Extensible & Configurable:** Easily adaptable to your workflow through themes and a comprehensive configuration system.
